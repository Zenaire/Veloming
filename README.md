## 🚀 Cara Menjalankan (Quick Start)

Pastikan **Node.js** (v18+) dan **Git** sudah terpasang di komputer Anda.

### 1. Clone Repository
```bash
git clone https://github.com/Zenaire/Veloming.git
cd Veloming
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Buka peramban (*browser*) dan akses:
```
http://localhost:5173
```

## 📜 Available Scripts

| Command | Deskripsi |
| :--- | :--- |
| `npm run dev` | Menjalankan local development server (`http://localhost:5173`) |
| `npm run build` | Mengompilasi kode TypeScript & bundling aset produksi ke folder `dist/` |
| `npm run preview` | Menjalankan preview lokal dari hasil build produksi |

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Routing**: React Router DOM v7
- **Animation**: Motion (`motion/react`)
- **Icons**: Lucide React
- **Build Tool**: Vite 6
- **Storage**: Browser LocalStorage (Zero setup / siap pakai)
